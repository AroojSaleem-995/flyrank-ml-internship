# Abstract

This project develops a machine learning approach to identify website pages that should be refreshed. A rule-based baseline scoring system was created using visibility, freshness, position, and content quality signals. A Random Forest model was then trained to predict declining pages using anonymized FlyRank search data. The model achieved competitive performance and produced ranked recommendations for content updates. These recommendations can help prioritize content refresh efforts.

---

# Introduction

Search rankings change continuously. Website content becomes outdated over time, causing decreases in impressions, clicks, and engagement.

The objective of this project is to identify pages that should be refreshed before their performance declines significantly.
